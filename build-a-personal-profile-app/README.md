# Jordan Leturgez - Frontend Developer, Writer, and Content Creator

This portfolio webpage showcases my skills, projects, certifications, and achievements in the fields of web development, machine learning, and creative coding. It is built with HTML, CSS, and JavaScript, featuring advanced techniques such as custom cursor effects, particle animations, and smooth scrolling.

## Features

- **Responsive Design**: The portfolio is fully responsive, optimized for both desktop and mobile devices.
- **Custom Cursor**: An interactive custom cursor with a follower effect for a unique user experience.
- **Particle Animation**: A dynamic particle effect adds a creative touch to the background.
- **Smooth Scrolling**: Smooth scrolling between sections for a seamless navigation experience.
- **Project Showcase**: A dedicated section highlighting my featured projects with detailed descriptions and technologies used.
- **Certifications & Achievements**: A section dedicated to my certifications and achievements, including FreeCodeCamp certifications and algorithm mastery.
- **Social Media Integration**: Links to my social media profiles, GitHub, CodePen, LinkedIn, and other platforms.
- **Performance Optimization**: Lazy loading of images and optimized code for faster loading times.
- **Easter Egg**: A hidden theme toggle feature accessible via keyboard shortcut (Ctrl+Shift+T).

## Project Structure

```
/index.html
/styles.css
/README.md
```

- **index.html**: Contains the markup for the portfolio, including the navigation bar, hero section, about me, projects, certifications, and contact sections.
- **styles.css**: Stylesheet with layout, colors, animations, and responsiveness.

## User Stories Fulfilled

1. **Welcome Section**: The portfolio includes a welcome section with the id `welcome-section`.
2. **Hero Text**: The welcome section contains a non-empty `<h1>` element.
3. **Projects Section**: The portfolio includes a projects section with the id `projects`.
4. **Project Tiles**: At least one project tile with the class `project-tile` is present.
5. **External Project Links**: Each project tile includes a link to an external project.
6. **Fixed Navbar**: A navbar with the id `navbar` is always fixed at the top.
7. **Navbar Links**: The navbar contains links that navigate to different sections on the page.
8. **Profile Link**: There is a profile link (`id="profile-link"`) that opens the GitHub profile in a new tab.
9. **Responsive Design**: The site uses a media query to improve mobile responsiveness.
10. **Viewport Height**: The welcome section height matches the viewport height.
